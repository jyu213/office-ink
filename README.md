# 我知道你着急，但是你先别急 · 职场水墨卡牌

一款可直接游玩的 Web 策略卡牌游戏。玩家用职场话术与电脑对战，卡牌采用原创水墨插画。进度、设置与战绩保存在当前浏览器的 IndexedDB，无服务端、无模型调用、无账户和付费系统。

## 开始开发

需要 Node.js 20 或以上，无需安装运行时依赖。

```bash
npm run dev
```

打开 http://127.0.0.1:5178 。指定端口可使用 `PORT=5180 npm run dev`。请通过 HTTP 访问，不要双击 HTML 使用 `file://` 打开。

```bash
npm test       # 核心规则与完整人机对局
npm run build # 生成 dist/ 静态站点
```

将 `dist/` 部署到任意静态站点托管即可。页面资源使用根路径，默认部署在域名根目录。

## 已实现

- 普通对局实时行动栏：统计可出手牌、可攻击立场和可用技能；点击数量可定位到对应区域。卡牌以文字、图标和边框区分可用、选中、目标与等待状态。
- 九步新手实战教学：首次进入可选择跟练，首页与玩法弹窗随时可进入；逐步高亮出牌、攻击、解锅与技能，支持重来和刷新续学。
- 44 种卡牌（另有临时帮手与后手补偿牌）：立场、话术与暗置伏笔；卡牌图鉴支持类型筛选、文字搜索与详情。
- 六套固定套牌：甩锅宗师、话术连招、流程大师、带薪摸鱼、画饼大师、复盘专家，每套 20 张，每种两张。每个流派有独立的主动技能，每回合可使用一次。
- 三档电脑：实习小白、资深同事、部门总监。普通难度按局面评分，并识别资源启动和挂锅的两步联动；困难难度对更多候选行动搜索两步。难度与对手流派独立选择。电脑不读取玩家的隐藏手牌、伏笔内容，也不预知抽牌顺序。
- 完整战斗：能量成长、召唤与交锋、拦截、突袭、连击、护盾、范围伤害、冻结、离场效果、挂锅与反制、沉默、退回、汲取、反伤、召唤、成长、牺牲、返聘与交接区回收、抽牌和疲劳、胜负与平局。
- IndexedDB 自动存档：每次行动结算后保存，可在电脑回合中离开，重新进入后电脑继续行动。
- 本地对局历史、胜率、套牌与难度偏好，以及可开关的合成音效。
- 桌面与手机布局、键盘按钮操作、弹窗焦点约束、减少动态效果偏好。

## 单人副本

点击导航栏的「副本」，进入「下班之前」。从六套预设卡组里选一套，依次挑战「晨会点名」「跨部门评审」和最终 Boss「季度述职」。一趟挑战使用同一套牌，每关重新洗牌，保留上关结束时的心态并恢复 8 点，最低补到 21 点，最高 25 点。落败可以从本关开局重试。

考核总监会在自己的第 3、6、9… 回合开始时发动「临时述职」，对你造成 2 点可被护盾抵挡的伤害。战斗上方会预告下次触发回合。副本独立自动存档，点击「返回副本」暂停，刷新后可从路线页继续。

## 新手怎么开始

第一次进入可点击「跟着打一局」，也可以从首页的「新手教学，带你打一局」进入；暂停后入口会变为「继续新手教学」，完成后可「重温新手教学」。玩法弹窗内也有跟练入口。

教学从准备好的残局开始，依次练习：看懂心态与精力 → 打出立场 → 等待下回合 → 处理锅 → 立场交锋 → 指定话术目标 → 使用技能 → 观察锅结算 → 直接攻击对手获胜。操作会调用正式战斗引擎，当前需要操作的牌或目标会高亮；错误操作只会提示，不会消耗资源。

教学有独立存档，不覆盖正式对局，不计入战绩。可中途退出、刷新后继续或重新开始。完成后会记住学习状态，不再自动弹出首次提示。

## 基本规则

双方 25 点心态，先将对方打到零即获胜。双方各从牌库抽 4 张，后手额外获得一张可临时增加 1 精力的「带宽临时扩容」。每回合开始抽 1 张。先手从 1 点精力开始，各自回合增加 1 点上限并回满，常规上限为 8 点；额外精力只在当回合有效。

- **立场**：占一个场位，最多 5 个。左下数值为压迫，右下为底气。普通立场入场当回合不能攻击；突袭可以立即攻击。立场交锋双方同时承受对方压迫，底气归零就离场。
- **话术**：立即结算，部分需点击目标。连击要求此前在本回合打过另一张话术牌。
- **伏笔**：暗置，满足触发条件时揭示并消耗。同一张伏笔不能重复埋设。
- **拦截**：限制立场攻击目标，敌方有拦截时必须先攻击拦截立场，话术不受限制。
- **锅**：最多 3 个。自己回合结束时，每个造成 2 点伤害，然后清空。回合内可花 1 点精力处理一个。
- **护盾**：抵挡心态伤害，持续到消耗为止，不保护立场。
- **手牌与疲劳**：手牌上限 8 张，溢出的抽牌弃置。牌库用尽后，每次抽牌受到递增的 1、2、3… 点疲劳伤害。

绿色「可出牌」表示现在能使用，绿色「可攻击」表示这个立场可以行动。橙色描边和文字标记表示选中后的合法目标；有拦截时会优先提示拦截目标。灰色牌显示精力不足、场位已满、需要护盾或等待下回合等原因，自己的回合可点击查看具体说明。

点击手牌即可出牌，带目标的话术需再次点选发光目标。攻击时先选就绪的己方立场，再选敌方立场或对手头像。右键卡牌可查看详情。按 Escape 取消选择或关闭弹窗。

「暂歇一下」会回到主页并暂停电脑行动，使用「继续对局」可恢复。未结束时新开一局会在界面提示，并将原对局记为落败。

## 数据与架构

```text
src/cards.js   卡牌、固定套牌、电脑档案
src/engine.js  纯状态转换、合法行动、胜负判定、电脑决策
src/tutorial.js 固定教学残局、步骤、操作校验与进度恢复
src/battle-guide.js 合法行动统计、卡牌可用状态与实时操作说明
src/storage.js IndexedDB 版本、事务与持久化
src/app.js     UI、目标选择、人机行动调度、音效
src/render.js  按标识复用 DOM，保持动画、焦点与滚动位置
src/style.css  宣纸、水墨卡面与响应式布局
assets/        水墨图集与站点图标
scripts/       无依赖开发服务器与静态构建
tests/         核心规则与浏览器交互回归
docs/          机制评审和可重现的对战模拟记录
```

数据库名为 `office-ink`，版本 1。`kv` 保存设置、当前对局和独立的 `tutorial` 教学进度、`dungeon` 副本进度；`matches` 以对局 ID 为键保存战绩，重复写入同一对局不会重复计数。对局规则版本为 2，第一版存档会保留原有对局、手牌和回合，并补齐技能与交接区字段后恢复；不兼容的未知版本不会继续加载。存储失败会在界面提示，当前内存对局仍可游玩。

所有数据仅存在当前浏览器、当前来源。隐私模式、清除站点数据、更换浏览器、域名或端口都会影响存档。无跨设备同步。

## 验证

`npm test` 覆盖出牌费用与不可变状态、拦截与话术绕过、连击前置、锅和护盾结算、伏笔保密与反制、锅位上限、突袭、冻结恢复、离场效果、胜负与疲劳、手牌和场位上限、存档与种子、电脑致胜选择与隐藏信息隔离，以及六套牌的全部对阵组合、各档难度、主动技能、全部新增关键词、旧存档迁移与后手补偿。

浏览器冒烟另通过本机无头 Chrome 验证；截图保存在开发时的 `/tmp/office-ink-shots/`，不计入站点资源。

渲染回归可在启动本地服务后运行 `npm run test:ui`。该项检查需要 Playwright 和本机 Chrome；可通过 `PLAYWRIGHT_MODULE` 指向已有 Playwright 的 `index.mjs`，通过 `CHROME_PATH` 指定浏览器路径，或在开发环境安装 Playwright。测试保持正常动画，逐帧检查选中、取消、出牌与弹窗时的战场位置、透明度和手牌滚动位置。


## 机制评审与模拟

本轮评审、六流派的连招与反制、后续建议见 [机制评审](docs/gameplay-review.md)。

`npm run simulate -- 12` 会运行六种流派的全部组合，每组 12 个固定种子，共 432 局普通电脑对战；默认行方先手，后手获得临时精力补偿。汇总记录在 [对战模拟](docs/matchups.json)。这类小样本模拟用于发现卡手、拖延和明显强弱，不等同于真人胜率或完成平衡认证。
