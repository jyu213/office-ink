# 你先别急 · 职场水墨卡牌

一款可直接游玩的 Web 策略卡牌游戏。玩家用职场话术与电脑对战，卡牌采用原创水墨插画。进度、设置与战绩保存在当前浏览器的 IndexedDB，无服务端、无模型调用、无账户和付费系统。

## 开始开发

需要 Node.js 20 或以上，无需安装运行时依赖。

```bash
npm run dev
```

打开 http://127.0.0.1:5178 。指定端口可使用 `PORT=5180 npm run dev`。请通过 HTTP 访问，不要双击 HTML 使用 `file://` 打开。

```bash
npm test       # 核心规则与完整人机对局
npm run build # 生成 dist/ 静态站点
```

将 `dist/` 部署到任意静态站点托管即可。页面资源使用根路径，默认部署在域名根目录。

## 已实现

- 24 种卡牌：立场、话术与暗置伏笔；卡牌图鉴支持类型筛选、文字搜索与详情。
- 三套固定套牌：甩锅宗师、话术连招、流程大师，每套 20 张，每种两张。
- 三档电脑：实习小白、资深同事、部门总监。普通难度按局面评分行动；困难难度增加两步搜索。电脑不读取玩家的隐藏手牌、伏笔内容，也不预知抽牌顺序。
- 完整战斗：能量成长、召唤与交锋、拦截、突袭、连击、护盾、范围伤害、冻结、离场效果、挂锅与反制、抽牌和疲劳、胜负与平局。
- IndexedDB 自动存档：每次行动结算后保存，可在电脑回合中离开，重新进入后电脑继续行动。
- 本地对局历史、胜率、套牌与难度偏好，以及可开关的合成音效。
- 桌面与手机布局、键盘按钮操作、弹窗焦点约束、减少动态效果偏好。

## 基本规则

双方 25 点心态，先将对方打到零即获胜。双方起手 4 张，每回合开始抽 1 张。先手从 1 点精力开始，各自回合增加 1 点上限并回满，常规上限为 8 点；额外精力只在当回合有效。

- **立场**：占一个场位，最多 5 个。左下数值为压迫，右下为底气。普通立场入场当回合不能攻击；突袭可以立即攻击。立场交锋双方同时承受对方压迫，底气归零就离场。
- **话术**：立即结算，部分需点击目标。连击要求此前在本回合打过另一张话术牌。
- **伏笔**：暗置，满足触发条件时揭示并消耗。同一张伏笔不能重复埋设。
- **拦截**：限制立场攻击目标，敌方有拦截时必须先攻击拦截立场，话术不受限制。
- **锅**：最多 3 个。自己回合结束时，每个造成 2 点伤害，然后清空。回合内可花 1 点精力处理一个。
- **护盾**：抵挡心态伤害，持续到消耗为止，不保护立场。
- **手牌与疲劳**：手牌上限 8 张，溢出的抽牌弃置。牌库用尽后，每次抽牌受到递增的 1、2、3… 点疲劳伤害。

点击手牌即可出牌，带目标的话术需再次点选发光目标。攻击时先选就绪的己方立场，再选敌方立场或对手头像。右键卡牌可查看详情。按 Escape 取消选择或关闭弹窗。

「暂歇一下」会回到主页并暂停电脑行动，使用「继续对局」可恢复。未结束时新开一局会在界面提示，并将原对局记为落败。

## 数据与架构

```text
src/cards.js   卡牌、固定套牌、电脑档案
src/engine.js  纯状态转换、合法行动、胜负判定、电脑决策
src/storage.js IndexedDB 版本、事务与持久化
src/app.js     UI、目标选择、人机行动调度、音效
src/style.css  宣纸、水墨卡面与响应式布局
assets/        水墨图集与站点图标
scripts/       无依赖开发服务器与静态构建
tests/        核心规则测试
```

数据库名为 `office-ink`，版本 1。`kv` 保存设置和当前对局；`matches` 以对局 ID 为键保存战绩，重复写入同一对局不会重复计数。存档包含规则版本，版本不兼容的旧对局不会继续加载。存储失败会在界面提示，当前内存对局仍可游玩。

所有数据仅存在当前浏览器、当前来源。隐私模式、清除站点数据、更换浏览器、域名或端口都会影响存档。无跨设备同步。

## 素材

水墨图集使用内置 imagegen 生成，最终素材在 `assets/ink-atlas.png`；来源与提示词见 `assets/README.md`。卡牌数值是可游玩的首版参数，后续可通过对局数据调整平衡。
