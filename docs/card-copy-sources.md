# 牌面文案参考

## 职场与互联网用语

- 「对齐」「颗粒度」「中台」「符合预期」出现在平台从业者访谈中。「对齐」常用于跨组协调目标、进度和工作细节。[毛天婵，《互联网“黑话”如何重塑平台内部管理制度》](https://znh.yzwb.net/zncontent/4989308.html)
- 「拉群」「闭环」「沉淀」用于灰度协作。团队用群聊跟进发布问题，把进展和反馈记录留在工单中。[飞书项目，灰度管理实践](https://project.feishu.cn/home/blogs/practice/grayscale)

## 产研发布用语

- 「灰度」是先让少量流量使用新版本做验证，验证通过后可进一步全量升级。发生异常时可「回滚」到历史版本。[腾讯云，应用升级与回滚概述](https://cloud.tencent.com/document/product/649/116506)

## 打工自嘲

- 「打工人」泛指各行各业的劳动者，也用来调侃自己的工作处境。「干饭人」「工具人」沿用类似的网络称呼形式。[李雪、张鑫，《“X人”构式的认知机制与传播动因》](https://qgxb.zzuli.edu.cn/fileZZQGYXYXBSKB/journal/article/zzqgyxyxbskb/2021/5/PDF/20210513.pdf)

## 游戏中的改写

- 「对齐下颗粒度」把逐字过稿写成对所有敌方立场造成伤害。
- 「先回滚一版」把退回旧版本写成将一个敌方立场退回手牌，同时清除其增益和状态。
- 「带薪回血」把午休续命写成攻击后恢复心态。

牌面台词为原创，借这些用语来描述游戏里已有的动作。
